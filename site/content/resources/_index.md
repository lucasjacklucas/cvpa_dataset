## Resources

### Exploration and Learning

- [Demographic Divides: Where to Start]({{< relref "where-to-start" >}}): recommended questions to explore for each demographic group, with notable gaps between groups and how those gaps changed over time.
- [Shifting Opinion: Where to Start]({{< relref "shifting-opinion" >}}): recommended questions for exploring how Canadian opinion has changed over time, including steady shifts, reversals, and sharp changes around particular events.

### Teaching

- [Sample Assignment]({{< relref "sample-assignment" >}}): a sample assignment using the CVPA data, for instructors to adapt.
- [Demographic Divides: Slides (PDF)](/resources/demographic-divides-slides.pdf): simple slides showing one question for each demographic group over time, for presentations and teaching.
- [Shifting Opinion: Slides (PDF)](/resources/shifting-opinion-slides.pdf): simple slides showing how Canadian opinion on several questions changed over time, for presentations and teaching.

### Data Analysis

- [CVPA R Package: Getting Started]({{< relref "cvpa-r-package" >}}): install the `cvpa` R package, download data for a question, compute weighted responses by year and by group, and plot the results.
- [Raw Data: Download, Open, and Use]({{< relref "raw-data" >}}): download `dataset.parquet` from GitHub, open it in R, understand how it is organized, and pull out a single question for analysis.
- [Adding Variables from the Original Surveys]({{< relref "adding-variables" >}}): add a question CVPA doesn't include by downloading the original survey files and linking them to CVPA respondents with `response_id`.
- [Rebuilding the Dataset from Scratch]({{< relref "rebuilding-the-dataset" >}}): for the (extremely rare and unlikely) case where you want to reproduce the entire CVPA dataset yourself by downloading the original survey files and running our build code.
